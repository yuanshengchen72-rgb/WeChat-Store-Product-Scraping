# 微信小店商品采集

## 卡密授权

- 软件启动前必须在线验证卡密，验证通过后才会进入采集界面。
- 不需要手机号或账号密码；卡密由管理员在 `https://api.dianchao1688.com/admin` 的“卡密管理”中直接生成。
- 每张卡密首次验证时绑定一台电脑。换电脑前需要在后台点击“解绑电脑”，原有效期不会重置。
- 卡密使用 Windows DPAPI 加密保存在当前用户的 `%LOCALAPPDATA%\WeChatShopScraper`，不会明文写入便携版目录。
- 后台停用或到期的卡密，下次启动软件时会立即被拒绝；断网时不能打开软件。

支持三种采集模式：电脑微信店铺列表、安卓手机微信关键词搜索，以及不连接手机的电脑版微信关键词搜索。采集字段：

- 商品 ID
- 关键词（店铺模式留空）
- 店铺名
- 标题
- 主图链接
- 列表展示价格
- 销量或销量展示文案

程序不会逐个点击商品详情，也不安装 HTTPS 根证书、不修改系统代理。店铺模式由用户手动滚动；两种关键词模式共用关键词、筛选、价格、断点、失败重试、去重、保存和每 1000 条分表规则。若筛选数据没有“好评多”，会直接跳过该关键词且不计为失败。安卓模式还会动态识别同一台手机中的主微信和微信分身（最多 6 个），某个微信确认无法返回搜索结果时自动切换下一个并重试当前关键词，最后一个失效后回到第一个继续循环。

## 安装

要求 Windows 10/11、桌面版微信和 Python 3.10 或更高版本。

最简单的方式是双击 `安装依赖.bat`，完成后双击 `启动采集.bat`。

项目固定使用 Frida 17.17.0，并在便携包中内置 arm64 手机端文件。新手机完成 Root、开启 USB 调试并连接数据线后，可点击“一键配置新手机”，软件会识别 CPU 架构、上传 Frida Server、设置权限、启动并验证通信。以后点击“开始采集”时也会自动检测并通过 Magisk Root 启动 Frida Server；已运行时不会重复启动。采集时可以选择 USB 数据线或局域网 WiFi 连接。

## 便携版

运行 `build_portable.ps1` 会在 `dist` 下生成 Windows 64 位便携 ZIP。接收方完整解压后直接运行 `微信小店商品列表采集.exe`，不需要安装 Python。便携目录中的 `_internal` 文件夹必须与 EXE 一起分发。

也可以手动安装：

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

## 店铺模式

1. 完全关闭此前的“葫芦娃-微店解析”，避免两个 Frida 监听器同时连接。
2. 打开桌面微信，进入目标微信小店。
3. 切换到店铺的商品双列列表页，并让窗口保持打开；此时先不要点击“销量”。
4. 启动本程序：

```powershell
.\.venv\Scripts\python.exe main.py
```

5. 点击软件里的“开始采集”，等待显示“监听中”。
6. 回到微信点击“销量”排序，让软件收到第一页请求。
7. 在微信中手动向下滚动到商品列表底部，触发所有分页加载。软件内表格会自动跟随最新采集的一条。

只点击“销量”但不向下滚动时，微信通常只返回第一页，无法采集完整店铺。

结果持续保存为：

- `data/products_001_年月日_时分秒.csv`、`data/products_002_年月日_时分秒.csv`……（每个 CSV 最多 1000 条，同一批使用相同时间）
- `data/products.json`

## 关键词模式（电脑版微信，不连接手机）

1. 完全退出其他电脑版微信采集软件；仅关闭窗口可能仍有后台核心占用本地调试端口，需在任务管理器确认它已经退出。
2. 登录电脑版微信，并保持微信主窗口已经显示。目前仅支持已核对的微信 `4.1.13.63`、`4.1.13.65`，对应小程序内核 WMPF `25558`、`25560`；4.1.15.x 已停止适配。未知版本会在挂载前停止并明确提示，不会冒险注入未知偏移。
3. 软件选择“电脑版微信关键词采集”，每行填写一个关键词，并按需填写最低价、最高价和定时重进小店的关键词数量。
4. 点击“开始采集”。软件会自动打开“小店与卡包”的商品搜索页、按关键词搜索、使用“商品”分类、应用“好评多”和价格筛选，然后直接读取全部分页；不需要连接手机，也不需要 ADB、Root 或手机端 Frida Server。
5. 筛选面板没有“好评多”时直接跳过且不计失败。普通失败间隔 60 秒重试 3 次；一个关键词用尽重试后跳到下一个，连续两个关键词都用尽重试才暂停。
6. 保存目录、断点续采、按商品 ID 去重、同一商品合并关键词、排除非商品卡片、表格时间戳及每 1000 条一个 CSV，全部与安卓手机关键词模式一致。电脑版和安卓模式的断点会按模式区分，避免互相续错位置。

电脑版关键词模式使用微信小程序内部的本地调试通道，端口 `127.0.0.1:9421` 必须空闲。同一台电脑不能同时运行两个占用该通道的电脑版采集工具；遇到“端口 9421 已被占用”时，请完全退出另一个工具及其后台核心后再开始。本模式只使用当前已登录的一个电脑版微信账号，不包含安卓模式的多分身轮换。

## 关键词模式（安卓手机）

1. 新手机先完成 Root 并开启 USB 调试，用数据线连接电脑，然后点击“一键配置新手机”。已配置过的手机可以直接连接。
2. 在手机微信进入“小店与卡包”，进入任意一个商品搜索结果页并保持微信在前台。
3. 软件选择“安卓手机关键词采集”，在“关键词列表”中每行填写一个完整关键词。需要限定价格时，在“预设价格”填写整数元，例如最低价 `50`、最高价 `500`；任一项留空表示该方向不限。
4. 点击“开始采集”。软件会逐个自动输入关键词并搜索。
5. 每个关键词出现稳定结果后，软件先点击顶部“商品”分类，再打开“筛选/已筛选”。若存在“好评多”，则确认勾选、清理旧价格并填写本批次预设区间，点击“确定”；软件必须检测到筛选结果版本已经更新并重新稳定后才会自动滚动，下滑期间结果版本变化会中止本轮并重试，避免混入筛选前商品。若不存在“好评多”，则关闭面板、记录“无好评多，已跳过”并立即切换下一个关键词，不进入失败重试。
6. 连续下滑间隔约为 `0.6` 秒；到达底部后仍会连续确认约 3 秒，确认没有新商品才自动切换下一个关键词。不需要填写滚动次数，也不需要点击商品或进入店铺。
7. “完整重启微信”可填写每隔多少个关键词执行一次，默认 `30`，建议 `20～30`；填 `0` 或留空表示关闭。这个设置会随断点保存，续采时自动恢复。
8. 开始前可点击“选择保存位置”，所选文件夹就是本批数据目录；选择空目录可开始全新批次，继续选择原目录则会读取原数据并按商品 ID 去重续写。未选择时默认保存在 `data/关键词采集汇总/` 下。全部完成后自动停止并导出，每 1000 个不同商品一个 CSV。同一批次始终复用第一次生成的时间戳；再次打开或续采时不会按启动次数重复生成 CSV，旧版留下的重复时间戳 CSV 会在成功导出后自动合并清理。

启动时软件会读取 Android 的用户/应用分身列表，自动识别已安装的 `com.tencent.mm` 实例，最多使用 6 个；不依赖手机序列号、固定 PID、分身名称或桌面图标位置。请先在各微信中登录，并从准备首先使用的微信进入“小店与卡包”搜索页。某个关键词无商品时，软件会用通用词做一次搜索自检：自检正常说明该关键词确实无商品，直接跳过而不切换；自检也无结果或结果始终无法稳定时，软件停止当前微信、启动下一个微信，自动进入“我 → 小店与卡包 → 搜索”，然后重新采集当前关键词。轮到最后一个微信后会回到第一个继续循环。登录失效、安全验证或“操作频繁”等明确风险页面仍会暂停并等待人工处理，不会用分身绕过验证。

达到界面设置的关键词间隔并记录断点后，软件会完整停止微信进程并重新冷启动，以释放微信和 XWeb 长批次积累的内存。冷启动主界面稳定后，软件先进入微信“我”页，再通过 Android 控件树或微信进程内视图精确定位文字“小店与卡包”的真实边界后点击，不再使用固定行坐标。进入原生搜索输入页后，软件会等待微信 Java 页面对象完成初始化并重试提交断点处的下一个关键词，等商品结果页出现，再连接该结果页的 XWeb 调试接口并继续采集；不会再把调试目标尚为空的搜索历史页误判为连接失败。若暂时识别不到准确入口，软件会等待重试而不会点击相邻的“作品”等菜单。这样可以避开微信主界面冷启动时过早注入导致的“微信没有响应”，也能适配不同分辨率、字体大小和账号菜单布局。完整重启路径失败时最多重试 3 次，仍失败才暂停整批任务。

完整重启流程同时兼容微信小程序页面的 `AppBrandPluginUI` 和 `AppBrandPluginUI1` 两种活动名称，避免页面实际已经打开但因名称尾缀变化而被误判为超时。

软件只在完整关键词已提交、结果稳定 2 秒后开始筛选和采集。筛选前后会锁定不同的搜索结果版本，商品卡没有“已售”文字时销量保留为空，不会把未知销量写成 `0`。所有关键词写入同一套滚动表格；普通商品按商品 ID 全局去重，同一商品命中多个搜索词时会在“关键词”单元格中用 `｜` 合并。直播商品卡片自动排除。出现登录失效、安全验证或页面异常时会暂停，不会静默跳过关键词。

价格区间对本次关键词列表中的所有关键词统一生效。微信价格键盘只支持整数元，软件会校验最低价不能大于最高价；例如 `50～500` 表示最低 50 元、最高 500 元。两个价格都留空时保持不限价格。

### 安卓手机通过 WiFi 采集

1. 电脑和手机连接同一个 WiFi，先用数据线连接手机并允许 USB 调试。
2. 软件选择“安卓手机关键词采集”，点击“通过 USB 启用 WiFi”。
3. 软件自动填写手机地址并提示连接成功后，即可拔掉数据线。
4. 保持连接方式为“WiFi无线”，填写关键词列表后点击“开始采集”。

WiFi 连接仅替代数据线，手机仍然需要 Root、USB 调试，且手机中需保留 Frida Server 文件。手机重启后，开始采集时软件会自动重新启动 Frida Server；但 ADB WiFi 通常仍需重新连接数据线并再次点击“通过 USB 启用 WiFi”。切换 WiFi 或局域网地址变化后需要更新软件中的地址。公共网络、访客网络或开启了设备隔离的路由器可能无法连接。

软件连接微信和 Frida 时会优先使用内置端口；如果端口已被 Chrome、其他采集窗口或其他程序占用，会自动选择可用端口继续启动，不需要用户关闭程序或手动修改端口。若 ADB 报告转发成功、但 Windows 随后返回 `10061` 拒绝连接，软件会主动删除失效映射、连续改用新的随机端口并验证真实连接，不会因为一个坏端口反复完整重启微信。

电脑同时连接多台已 Root 手机时，USB 模式会严格按照 ADB 序列号选择对应的 Frida 设备，不会误连另一台 WiFi 手机。手机端自动输入通过当前 Activity 表定位微信搜索页，不进行全 Java 堆扫描，避免新版本微信上长期卡在“正在自动输入并搜索”。

自动提交搜索后，部分微信版本会重启主进程或重建 XWeb 调试通道。软件会检测微信 PID 变化，重新注入调试脚本、重建端口转发并继续等待当前关键词结果，不需要重新点击“开始采集”。

长批次中，完整重启后的原生搜索输入页不会立即提供可用的 XWeb 调试目标。软件会先输入并提交当前关键词，等商品结果页开放调试目标后再连接，不会因此重复点击“小店与卡包”或误判为关键词失败。

### 一键配置新手机

1. 先按照该手机型号对应的方法完成 Bootloader 解锁和 Magisk Root；这两步不会由采集软件执行。
2. 开启 USB 调试，用数据线连接电脑，并在手机上允许这台电脑调试。
3. 软件切换到“安卓手机关键词采集”，点击“一键配置新手机”。
4. 如果 Magisk 弹出 Shell Root 授权，选择永久允许。
5. 等待软件完成架构识别、约 51 MB 文件上传、权限设置、启动和通信验证。

当前便携版内置 `arm64-v8a` 版本，适用于绝大多数现代安卓手机。其他 CPU 架构会给出明确提示，不会上传错误文件。

采集过程中可以查看 CSV。若当前批次的 `products_001_年月日_时分秒.csv` 正被 WPS/Excel 占用，程序会继续在软件列表中显示商品并保存 `products.json`，同时提示“CSV待更新”；关闭表格文件后，在下一批商品或点击“停止”时会自动重试导出 CSV。

无法识别的列表响应会保留在 `data/.cache/debug/`，最多 30 份，便于微信升级后调整字段解析规则。界面中的“清理软件缓存”只删除这些调试缓存，不会删除商品 CSV/JSON、关键词断点、卡密或选择的保存位置；采集运行期间不能清理。

## 字段说明

- `price_fen` 使用“分”为单位，`14900` 表示 `¥149.00`。
- “关键词”在电脑版或安卓关键词模式填写，店铺模式保持为空。
- 店铺名来自微信列表响应的 `platform_name` 字段，并写入每条商品记录。
- `sales_exact=false` 表示店铺只提供了“1.2万+”之类的展示文案，数值是近似换算。
- 列表价格通常是最低 SKU 价或活动展示价，不等同于每个 SKU 的完整价格。
- 如果某个店铺列表根本不展示销量，微信可能不会在列表返回精确销量；这种情况下本工具会保留空值，而不会把店铺总销量误写成单品销量。

## 常见问题

### 找不到 ILinkServiceHost

先进入微信小店页面再点击“开始采集”。如果微信刚升级，完全退出微信（包括托盘）后重新打开。

### 启动时提示缺少 frida

确认使用安装依赖的同一个 Python：

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

电脑版关键词模式也需要便携包或项目环境中包含电脑端 Frida Python 组件，但不需要手机端 Frida Server；便携包已将该组件一并打包。

### 电脑版关键词模式提示端口 9421 被占用

另一个电脑版采集工具仍在运行，或它的后台核心没有随窗口退出。请先完全退出该工具，并在任务管理器确认对应后台进程已结束，再重新点击“开始采集”。软件不会自动结束别的程序，以免误伤正在运行的任务。

### 为什么要先开始采集再点销量

点击“销量”会立即触发第一页列表请求。如果先点销量、后开始采集，软件会错过第一页。正确顺序是：开始采集 → 点击销量 → 手动滚动到底。

### 日志显示解析到商品，但软件列表为空

请先确认运行的是最新便携包。关键词模式不需要填写滚动次数，软件会根据“到达底部且没有新商品”自动结束当前关键词。旧版在 CSV 被 WPS/Excel 占用时可能中断界面刷新；最新版会继续显示商品并保存 JSON。
