# 2026-09-13 稳定性优化

本轮针对“能输入关键词但偶发中断、微信崩溃”的证据链做了小范围修复：

- 原生后台命令的 task 和 UTF-8 字符串在收到回包前保持引用；回包后显式释放，120 秒兜底回收，并限制同时保留的任务数。
- 移除没有消费者的 WMPF `on-command` 高频钩子，减少无效拦截。
- 采集逻辑层未绑定时，优先重新触发已验证的小店入口；只有运行时已确认安全时才走原生重启。
- 搜索状态的一次性“页面仍在初始化”错误改为有界重试；重复出现模块缺失仍立即报告为结构性错误。
- 自动恢复最多尝试 5 次并保留关键词断点，避免在异常宿主上无限关闭/启动微信。
- 已显示搜索页的现有小店不再重复发送原生启动；若 25560 在钩子装载后立即
  `process-terminated`，标记为内核偏移兼容性故障并停止恢复，避免循环崩溃。
- 真实 A/B 已确认 25560 的 `0x3979600` 过滤器入口在页面创建流程中不触发；已停用
  该入口及其 `+8` 写入，保留可实际建立 AppIndex/逻辑层会话的场景入口。
- 逻辑层未绑定不再伪装成宿主进程失效，避免对仍存活的小程序反复摘挂钩子。
- 内置入口失败时若没有独立文件传输助手，不再把主故障改写成“请打开文件传输助手”。
