微信小店商品采集 - 便携版

适用环境：Windows 10/11 64 位；支持电脑版微信店铺、安卓手机关键词、电脑版微信关键词三种模式。
不需要安装 Python，不需要安装 Frida，不需要配置系统代理或证书。

卡密验证：
1. 双击“微信小店商品列表采集.exe”后，先粘贴管理员提供的 WXS- 开头卡密。
2. 卡密验证成功后才会进入采集界面；软件每次启动都需要联网校验。
3. 一张卡密只绑定一台电脑。换电脑时，请管理员在后台“卡密管理”里先点“解绑电脑”。
4. 不需要手机号；卡密会用 Windows 加密机制保存在当前电脑用户中，不会明文留在便携目录。

店铺模式：
1. 必须先完整解压 ZIP，不能直接在压缩包内运行。
2. 登录电脑版微信，进入目标小店的“商品”列表页，此时先不要点击“销量”。
3. 双击“微信小店商品列表采集.exe”。
4. 点击“开始采集”，等待软件显示“监听中”。
5. 回到微信点击“销量”排序，然后手动向下滚动到列表底部。
6. 软件内的商品表格会自动跟随到最新采集的一条。
7. CSV 和 JSON 会保存在程序同级的 data 文件夹。
8. CSV 每 1000 个商品自动生成一个文件，文件名带本批保存时间，例如 products_001_20260903_131522.csv。
9. 每条商品都会同时保存所属店铺名。

电脑版微信关键词模式（不连接手机）：
1. 完全退出其他电脑版微信采集软件；仅关窗口后仍可能有后台核心占用调试端口。
2. 登录电脑版微信并显示主窗口。当前已验证微信 4.1.13.63、小程序内核 WMPF 25558；不一致时软件会安全停止并提示。
3. 软件选择“电脑版微信关键词采集”，每行填写一个关键词，并按需设置最低价、最高价和定时重进小店的间隔。
4. 点击“开始采集”。软件自动打开“小店与卡包”搜索页，切到商品，使用“好评多”和价格筛选，并读取全部分页。
5. 该模式不需要手机、数据线、ADB、Root 或手机端 Frida Server。
6. 没有“好评多”时直接跳过；失败重试、断点续采、商品去重、时间戳及每 1000 条一个 CSV 与安卓关键词模式一致。
7. 本地端口 127.0.0.1:9421 必须空闲；不能同时运行两个电脑版采集工具。本模式使用当前登录的一个电脑版微信账号，不进行手机微信分身轮换。

安卓手机关键词模式：
1. 新手机先完成 Root 并开启 USB 调试，用数据线连接电脑后点击“一键配置新手机”。软件会识别 arm64 架构、上传 Frida Server 17.17.0、设置权限、启动并验证通信。
2. Magisk 首次弹出 Shell Root 授权时请选择永久允许；Bootloader 解锁和 Magisk Root 不能由本软件自动完成。
3. 已配置手机开始采集时，软件会自动检查并启动 Frida Server，可使用 USB 或 WiFi 连接电脑。
4. 在手机微信进入“小店与卡包”，进入任意一个商品搜索结果页并保持微信在前台。
5. 软件选择“安卓手机关键词采集”；在“关键词列表”中每行填写一个完整关键词。
6. 如需限定价格，在“预设价格”填写整数元。例如最低价 50、最高价 500；任一项留空表示该方向不限，两个都留空表示不限价格。该区间对列表中的所有关键词生效。
7. 点击“开始采集”。软件会逐个自动输入关键词、搜索、点击顶部“商品”分类、打开“筛选/已筛选”、选择“好评多”、清理并填写预设价格，然后点击“确定”。确定后必须检测到筛选结果版本已经更新并重新稳定，才会开始下滑；下滑期间版本变化会立即中止本轮重试，避免混入筛选前商品。若某个关键词没有“好评多”选项，会直接跳过且不计为失败。
8. 每个关键词会自动快速向下滚动；连续下滑间隔约 0.6 秒，到达底部后仍会连续确认约 3 秒，确认没有新商品才切换下一个关键词，不需要设置滚动次数。
9. 不需要点击商品或进入店铺；“全部”页中的直播商品会自动排除。
10. “完整重启微信”可填写间隔关键词数，默认 30，建议 20～30；填 0 或留空表示关闭。该设置随断点保存，续采时自动恢复。
11. 开始前可点击“选择保存位置”；所选文件夹就是本批数据目录。选择空目录开始全新批次，继续选择原目录则按商品 ID 去重续写；未选择时默认保存到 data\关键词采集汇总\。每 1000 个不同商品一个 CSV，文件名带本批首次保存时间，例如 products_001_20260903_131522.csv。同一批续采不会生成新时间戳；旧版留下的重复时间戳 CSV 会在成功导出后自动合并清理。
12. 商品按 ID 全局去重，同一商品命中多个搜索词时，“关键词”单元格会用 ｜ 合并。
13. 普通页面失败时，软件会等待 60 秒后重试当前关键词，最多重试 3 次；等待期间点击“停止”可立即结束，不必等满一分钟。
14. 一个关键词重试 3 次仍失败时会记录并跳到下一个；若紧接着的下一个关键词也重试失败，整批任务才暂停。中间任一关键词成功后，连续失败计数会清零。
15. 软件会在 data\关键词采集汇总\keyword_checkpoint.json 保存完整关键词列表、价格区间、微信重启间隔和当前位置。手动停止、异常暂停或软件重开后会自动回填并从断点继续；全部完成后自动清除断点。
16. 登录失效、安全验证、操作频繁等需要人工处理的页面会立即暂停，不进行自动重试，避免触发更严格限制。
17. 达到设置的关键词间隔并记录断点后，软件会完整停止微信进程并重新冷启动，以释放长批次积累的内存。主界面稳定后先进入“我”，再通过 Android 控件树或微信进程内视图精确识别“小店与卡包”的文字边界后点击，不再使用固定行坐标；识别不到时只等待重试，不会误点相邻的“作品”等菜单。进入原生搜索输入页后，软件会等待微信 Java 页面对象完成初始化并重试提交断点处的下一个关键词，等商品结果页出现，再连接该结果页的 XWeb 调试接口并继续采集；不会把调试目标尚为空的搜索历史页误判为连接失败。完整重启路径失败最多重试 3 次，仍失败才暂停。
18. 软件会通用地识别 Android 主用户和应用分身中的微信，最多 6 个，不绑定手机序列号、PID 或桌面图标。当当前微信无搜索结果时，会先用通用词自检，避免冷门词误触发切换；确认搜索失效后自动切到下一个微信、进入“我 → 小店与卡包 → 搜索”并重试当前关键词。最后一个微信失效后回到第一个继续循环。登录失效、安全验证或“操作频繁”等明确风险页面仍会暂停等待人工处理。

WiFi 连接：
1. 电脑和手机连接同一个 WiFi，首次先用数据线连接手机并允许 USB 调试。
2. 点击软件里的“通过 USB 启用 WiFi”，提示成功后即可拔掉数据线。
3. 保持连接方式为“WiFi无线”，再开始采集。
4. 手机重启、切换 WiFi 或地址变化后，通常需要插线重新启用一次。

注意：
- 请保留 exe 与 _internal 文件夹的相对位置，不要只复制 exe。
- 电脑版关键词模式若提示端口 9421 被占用，请完全退出其他采集软件及其后台核心；本软件不会自动结束别的程序。
- 若提示找不到微信进程，请先打开小店商品列表，再重新开始采集。
- 若普通启动无法连接微信，可右键 exe，选择“以管理员身份运行”。
- 若默认连接端口被 Chrome 或其他程序占用，最新版会自动改用可用端口；若 Windows 返回 10061 拒绝连接，还会删除失效的 ADB 映射、连续换新端口并验证真实连接，无需手动处理。
- 同时连接多台手机时，USB 模式会严格选择软件中识别到的手机序列号，不会误连另一台 WiFi 手机。
- 若自动搜索导致微信主进程重启或 XWeb 调试通道变化，软件会自动重新连接并继续当前关键词；无需退出微信或重新开始。
- 完整重启后会先在原生搜索输入页提交当前关键词，等商品结果页出现可用的 XWeb 调试目标后再连接，不会重复点击入口。
- 完整重启兼容微信小程序页面的 AppBrandPluginUI 和 AppBrandPluginUI1 两种活动名称，页面已经打开时不会因名称尾缀变化误判超时。
- 若价格区间位于筛选面板下方，软件会自动滚动筛选面板后填写最低价和最高价。
- 安卓关键词商品卡没有显示“已售”文字时，销量会保留为空，不会再把未知销量写成 0。
- 若 CSV 正在 WPS/Excel 中打开，软件仍会继续显示商品并保存 JSON；关闭表格后，在下一批商品或点击“停止”时会自动重试更新 CSV。
- “清理软件缓存”只删除软件产生的调试缓存，不会删除商品 CSV/JSON、关键词断点、卡密或选择的保存位置；请先停止采集再清理。
- 关键词模式不需要填写滚动次数；“自动滚动到底”是固定流程，不单独显示次数选项。
- Windows 安全软件可能会检查未签名的便携程序；本程序不会安装证书或修改系统代理。
